Typography

System font stack (SF Pro / Roboto). Weights: 400 (body), 600 (labels), 700 (headings), 800 (numbers/stats). Scale: 11px micro → 13px caption → 14px body → 16-22px headings → 28-48px display numbers.

Design Principles

  • Camera-first: App opens directly to camera — zero taps to start scanning
  • Instant feedback: Stepped progress indicators keep users engaged during analysis
  • Glanceable data: Rings, bars, and color coding let users absorb info without reading
  • Confidence signals: Show AI confidence % to build trust and set expectations
  • Actionable insights: Don't just show numbers — provide context and suggestions
  • Adjustability: Users can correct AI mistakes (portion size, food identification)

User Flow

Happy path: Open app → Point camera → Tap shutter → Review photo → Tap "Analyze" → View results → Tap "Log Meal" → Done.
Total taps from open to logged meal: 3 (shutter → analyze → log)

Navigation Structure

5-tab bottom navigation: Log (history) · Today (daily food log) · Snap (camera — center) · Insights (summary & AI tips) · Settings (profile & goals)
